# 3D PARTY WORLD — 게임 디자인 문서 (GDD)

> 버전 0.1 · 2026-11-22 · 상태: Phase 1 (기획/설계) 완료, Phase 2·4 일부 구현

## 1. 한 줄 소개
귀엽고 통통한 캐릭터들이 하늘 위 광장에 모여, 친구들과 PC·모바일 구분 없이 장애물 레이스·생존·레이싱·협동·파티 미니게임을 즐기는 온라인 파티 게임.

## 2. 디자인 원칙
| 원칙 | 의미 | 설계에 미치는 영향 |
|---|---|---|
| **누구나 3초 안에** | 어린이~어르신이 설명 없이 조작 | 이동 + 점프 + 상호작용 버튼 1개가 전부. 가상 조이스틱 크게. |
| **함께가 즐겁다** | 승리보다 "같이 논 기억" | 참여·협동 보상, 꼴찌도 재미있는 연출 (넘어지기, 감정표현) |
| **공정함** | 기기·지갑과 무관한 승부 | 서버 권한 판정, 동일 물리, Pay-to-Win 금지 |
| **안전함** | 아이도 쓰는 서비스 | 공개 채팅 기본 OFF, 프리셋 감정표현/퀵메시지 중심 |
| **계속 새롭다** | 장기 운영 | 게임 모드/맵을 모듈로 추가하는 구조 |

## 3. 핵심 게임 루프
```
로비(광장) 자유 이동·꾸미기·친구 만나기
   → 포털/메뉴에서 모드 선택 (빠른 매칭 · 방 코드 · 친구 초대)
   → 대기실 (최대 8명, 준비)
   → 라운드 진행 (모드별 규칙, 서버 판정)
   → 결과 (순위 + 참여/협동 보상 + 경험치)
   → 로비 복귀
```
세션 목표 길이: 라운드 2~4분, 한 판(대기~결과) 5분 이내.

## 4. 캐릭터
- **콘셉트**: 큰 머리 + 둥근 몸통의 2.5등신 "말랑이" 캐릭터. 짧은 팔다리, 볼터치, 머리 위 새싹(기본 모자).
- **현재 구현**: 프리미티브 기반 프로토타입 모델 (`scripts/player/character_visual.gd`). 리그 노드명·애니메이션명이 고정되어 있어 Blender GLB로 교체해도 게임 코드 변경 없음.
- **애니메이션(구현 11종)**: idle, walk, run, jump, fall, land, wave, dance, victory, defeat, knockdown
- **커스터마이징(구현)**: 몸 색 8종, 모자 5종 (sprout/none/cap/crown/bow). 예정: 표정, 의상, 액세서리, 신발.
- **수치**: 이동 6.5 m/s, 점프 높이 ≈1.92 m, 코요테 타임 0.1 s, 계단 자동 오르기 0.35 m.

## 5. 조작 (크로스플레이 동일 규칙)
| 행동 | PC | 모바일 |
|---|---|---|
| 이동 | WASD/방향키 (Shift=걷기) | 왼쪽 가상 조이스틱 (기울기=속도) |
| 카메라 | 마우스 (클릭 시 캡처), 휠 줌 | 오른쪽 화면 드래그, 핀치 줌 |
| 점프 | Space | 점프 버튼 |
| 상호작용 | E | 상호작용 버튼 |
| 감정표현 | 1~4 | 감정표현 휠 버튼 |

**공정성**: 이동은 서버가 `길이 ≤ 1`로 제한된 방향 벡터만 받으므로 키보드 대각선이 조이스틱보다 빠를 수 없다 (테스트로 검증됨). 마우스 카메라 이점이 큰 모드(조준 등)는 만들지 않는다.

## 6. 로비 — "하늘 위의 광장"
- 구름 위 떠 있는 원형 섬(반지름 28m), 중앙 분수, 나무·벤치, 전망대(경사로), 계단, 점프 도전 발판.
- 5개 게임 모드 포털이 분수 북쪽 반원에 배치.
- 섬 밖으로 떨어지면 서버가 스폰 지점으로 리스폰.
- 예정: 상점·미션·랭킹·이벤트 게시판 NPC/키오스크, 꾸미기 거울, 친구 초대 우편함.

## 7. 게임 모드 (출시 목표 5종, 첫 번째는 장애물 레이스)
| 모드 | 인원 | 규칙 요약 | 승리 외 보상 |
|---|---|---|---|
| **장애물 레이스** (최우선) | 2~8 | 회전 막대·움직이는 발판·밀어내는 벽을 지나 결승선. 상위 N명 통과. | 완주, 체크포인트, 넘어진 친구 근처 응원 |
| 생존 게임 | 2~8 | 바닥 타일이 사라지거나 공이 굴러옴. 마지막까지 버티기. | 생존 시간 |
| 레이싱 | 2~8 | 귀여운 카트/풍선 탈것 3바퀴. 아이템 없음(공정성). | 개인 기록 갱신 |
| 협동 미션 | 2~8 | 함께 버튼 누르기·물건 옮기기로 제한 시간 내 목표 달성. | 팀 전원 동일 보상 |
| 파티 미니게임 | 2~8 | 30~60초 짧은 게임 랜덤 3종 (과일 모으기, 얼음땡 등). | 참여 점수 |

맵 테마 후보: 하늘 섬, 장난감 마을, 정글, 얼음 왕국, 바닷속, 우주, 사막, 판타지 왕국.
모든 모드는 `GameMode` 공통 인터페이스(TECHNICAL_DESIGN.md §5)를 구현한 독립 모듈.

## 8. 성장·보상 (Phase 7)
- 계정 레벨/경험치: 참여(기본) + 순위 보너스 + 협동 보너스. 꼴찌도 참여 경험치의 70% 이상.
- 일일/주간 미션, 업적, 시즌 이벤트.
- 보상: 외형 아이템·감정표현만. **능력치 아이템 없음 (Pay-to-Win 금지)**.
- **금지**: 확률형 뽑기, 유료 랜덤 박스, 과도한 결제 팝업. 상점은 가격이 명시된 직접 구매만.

## 9. 소통·안전
- 공개 텍스트/음성 채팅: 기본 비활성.
- 프리셋 퀵메시지("안녕!", "같이 하자!", "잘했어!")와 감정표현.
- 친구 간 채팅은 보호자 설정/연령 확인 이후 검토.
- 신고·차단, 닉네임 필터(서버 검증: 2~16자, 한글/영문/숫자/_).

## 10. 아트 방향
- 파스텔 톤, 2단 셀 셰이딩 + 약한 림 라이트(`shaders/toon.gdshader`), 텍스처 최소화(모바일 성능).
- 둥근 형태, 날카로운 모서리 없음. 그림자는 푸른 기운.
- 최종 에셋: Blender → GLB. 폴리곤 예산: 캐릭터 3~5k tris, 로비 전체 150k tris 이하(모바일 기준, 실기기 측정 후 확정).
